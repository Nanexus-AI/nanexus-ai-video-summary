# MODEL-001～006 OpenCLIP Provider migration acceptance

- Date: 2026-08-21
- Status: stage 4 exit conditions passed; stage 5 not started

## Result

Video Summary now owns a worker-only Provider interface and configurable Stub/OpenCLIP implementations. OpenCLIP provides image/text embeddings and versioned zero-shot labels; it is explicitly not represented as a VLM or free-form caption model. Heavy imports are lazy and confined to the enrichment Worker. FastAPI defaults to keyword fallback and cannot load the model unless the frozen legacy rollback switch is explicitly enabled.

Evidence is fetched only through the authenticated, job-scoped Event Intelligence API. The Worker accepts only bounded JPEG/PNG/WebP, verifies image decoding with Pillow, never receives a source URL or Frigate credential, and submits auditable abstention for permanent media failures. Retryable model failures submit no terminal Result, leaving the base-owned Job available for retry.

## Traceability

The Worker records Provider, model, pretrained variant, resolved device, label-set version, latency, Provider result hash and Evidence ID. The public Result carries the bounded model identity; Event Intelligence creates the authoritative ModelInvocation, result hash and Claim/Invocation Evidence associations. The base Result endpoint now persists invocation `latency_ms`.

## End-to-end evidence

An isolated Compose run seeded Event Intelligence's sanitized Frigate lifecycle fixture through its own ingest pipeline and served a generated, credential-free snapshot. Both runs used only public Processor APIs between repositories:

1. Stub: succeeded Caption Claim, `deterministic-stub@1.0+stub-labels-v1+cpu`, Evidence association, 69 ms persisted latency.
2. OpenCLIP CPU: succeeded Caption Claim, `ViT-B-32@openai+security-camera-en-v1+cpu+3.3.0`, Evidence association, 242 ms persisted latency.

The OpenCLIP Claim text was `OpenCLIP zero-shot labels: person wearing red clothes, red car, person at the front door`. This is a fixed-fixture quality observation, not a general accuracy claim.

## Boundary and rollback

No shared database, ORM, internal Redis key, filesystem media path or reverse dependency was introduced. Video Summary does not construct Frigate URLs or receive Frigate tokens. Legacy MQTT/Event/AI/Search paths remain present. `MODEL_PROVIDER=stub` is the safe default; omitting `compose.model.yaml` leaves the Stub image selected. Cloud providers remain unsupported and disabled.

## Known limitations and stop condition

- The first quality baseline is a synthetic single image and English label set only.
- Python thread-pool tests must run outside the current Codex Bubblewrap because that sandbox blocks the default asyncio executor; runtime and Compose are unaffected.
- Model weights/license and QuickGELU compatibility still require release-stage review.
- No EmbeddingRecord, vector migration, semantic Search API or reindex workflow was started. Stage 5 requires separate authorization.
